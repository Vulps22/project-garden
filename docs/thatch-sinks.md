# Thatch sinks

Ways for a player with thousands of Thatch to spend it. The currency is [[economy]]; the scoreboard ranks current
Thatch, so spending costs rank, and that is the tension ([[scoreboard]]).

## Candidates

**Status (2026-11-04):** proposed, not chosen ([[todolist]]).

Ranked by how much each would drain:

1. **Extra Plots:** about 1,500 × Plots held for each deed after the first, or the Plot Seed
   ([[roadmap#Future — buying more garden|roadmap → buying more garden]]).
2. **Show seeds as luxuries:** Moonflower about 1,200, tulip about 400, popcorn about 800 ([[fun-seeds]]).
3. **Grow Wand charges:** 50–150, at or above the crop's profit ([[dev-tools]]).
4. **Standing-crop upgrades** as rare seeds at 300–1,000 ([[roadmap]]).
5. **Paid early restock of one stall,** 100–300; the restock timer button does nothing yet ([[shop]]).
6. **Plot decorations.** Needs assets.

- **Not ranking by Thatch earned** (Vulps, 2026-11-04): the board ranks current Thatch, so spending is a decision.
- **Not charging for teammates:** it taxes the social feature.
- Thatch will persist ([[persistence]]), so an upgrade can pay back over several sessions.
