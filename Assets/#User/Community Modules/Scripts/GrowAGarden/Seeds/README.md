# Seed Definitions

One `SeedDefinition` subclass per crop; the numbers are code, not Inspector values. The current table and how to
add a crop are in `docs/crops.md` → Balance, which is the source of truth.

Tomato and eggplant regrow for a season (`harvestCount` 3, `MultiHarvestPlant`); corn is a rooted crop.
See docs/crops.md.
